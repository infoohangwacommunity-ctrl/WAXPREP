# Third-Party Licence Policy

Wax Prep may copy or adapt third-party code only when its licence permits that use and the provenance is recorded.

Preferred licences:

- MIT
- Apache-2.0
- BSD-family licences

Before copying code:

1. Identify the original repository and file.
2. Read the actual licence.
3. Confirm the intended use is permitted.
4. Preserve required attribution notices.
5. Record the source, licence, and what was copied or adapted.

A public GitHub repository is not automatically reusable.

AI-generated code is not automatically free of third-party licensing concerns.

This is a project policy, not legal advice. A qualified lawyer should review licensing questions that materially affect distribution or ownership.
